# Audit — 2026-09-04

A whole-project audit run after the cloud deployment: `/code-review` at high effort
plus six parallel deep dives (accounting, tenancy, dates/i18n, framework, the AI
assistant, the test suite), following the systematic-debugging discipline — root
cause before fix, trace to the original trigger, a failing test before each change.

Every finding below was verified by reading the code. Findings that could not be
demonstrated with a concrete wrong result were dropped rather than listed.

**Status column:** `fixed` (with the commit), `open` (accepted, not yet done),
`decision` (needs a product call), `wontfix` (deliberate, recorded so the next
audit does not re-raise it).

## Method

`/code-review` at high effort over the unreviewed commits in `lib app components`,
plus six read-only deep dives run in parallel, each told to report only findings it
could demonstrate with a concrete wrong result and to quote the code. Every finding
in sections A–G was then re-verified directly before being written down; the
citation-gate regex in C2 was confirmed by executing it. Findings the agents raised
that did not survive that check are not listed.
